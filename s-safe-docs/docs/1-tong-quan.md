# Giới thiệu hệ thống S-Safe

Chào mừng bạn đến với tài liệu hướng dẫn chính thức của phần mềm an ninh **S-Safe**.

## Các module chính
Hệ thống được chia thành các module cốt lõi sau:
* **Cardholder:** Quản lý thông tin thẻ và nhân sự.
* **Access Control:** Phân quyền và kiểm soát cửa ra vào.
* **Alarm Monitoring:** Giám sát trạng thái thiết bị và bản đồ E-Map.

> **Lưu ý:** Vui lòng đọc kỹ hướng dẫn cài đặt Server trước khi thao tác trên phần mềm.
