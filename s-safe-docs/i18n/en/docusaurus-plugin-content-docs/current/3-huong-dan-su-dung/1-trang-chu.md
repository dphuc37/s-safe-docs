# S-Safe Home Screen Interface

The main interface displayed after logging in with an authorized account provides key sections to help users navigate and manage the system with ease. You can click the Menu icon to collapse the Sidebar.

## Main Components

1. **Sidebar Menu (Navigation Menu):** Located in the left column, it displays all tasks and functions of the software (Administration, Operations, Maintenance, Reports, etc.). Click the S-Safe logo to collapse the sidebar.
2. **Tab Control (Tab Bar):** Located at the top, it allows you to manage and switch between currently open functional modules.
3. **Dashboard (Main Module Panel):** The central area that visually displays icons for the main functional modules for quick access.
